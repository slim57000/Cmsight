# Highlights foot TikTok

- `clips/` : tes extraits (.mp4/.mov), ex. `video.mov`
- `memes/` : memes **vidéo** (.mp4/.mov, avec leur son) incrustés après chaque impact
- `music/` : ton son rap/trap (.mp3) — libre de droits, ou ajoute le son TikTok dans l'app
- `python3 make_highlight.py [--duree 8] [--meme 2] [--texte "GOAL"]` → `output/highlight_tiktok.mp4`

Effets : ralenti à l'impact, punch zoom + shake, split RGB, flash blanc, vignette, texte, meme vidéo + son.
