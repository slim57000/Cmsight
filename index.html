Ce que fait le logiciel

Un assistant qui connaît votre CMS

WordPress, WooCommerce, PrestaShop, Joomla, Drupal. Il détecte le CMS à la connexion et écrit du code adapté à sa structure, pas des snippets génériques.

Aperçu avant, sauvegarde pendant

Vous voyez le diff avant/après de chaque fichier. À l'application, l'original est copié de côté : vous restaurez en un clic si le résultat ne vous plaît pas.

Local, FTP ou SFTP

Un dossier sur votre disque, un hébergement mutualisé en FTP, ou un serveur en SFTP. La connexion se configure en deux minutes.

Pas de compte, pas de cloud

Vos sites, vos identifiants et vos clés API restent sur votre PC. Un mot de passe protège l'accès au lancement.

L'application

Vos sites restent chez vous.

Rien n'est stocké sur un serveur Cmsight. Les fichiers de votre site, vos clés API et vos accès FTP ne quittent jamais votre machine, et aucune modification n'est écrite sans votre validation.
